微信聊天导出器 1.1.2

使用
1. 先登录电脑版微信。
2. 双击“微信聊天导出器.exe”。程序会显示微信记录根目录（例如 F:\微信记录\xwechat_files）。点击“目录”可更改这一层路径，然后在下方带微信名和头像的下拉菜单中选择账号。
3. 点击“读取 / 更新记录”。首次会进行密钥验证、数据库解密和消息索引，耗时与记录量有关。
4. 左侧搜索并选择会话，会话列表与消息旁显示本地缓存头像。右侧可按开始、结束时间筛选；时间为北京时间，包含起止时刻，精确到秒。
5. 在“导出格式”下拉框选择 HTML（单文件）、PDF 文档或 Markdown（.md），点击“导出”并选择保存位置。消息预览每批200条；导出包含所选时间范围的全部消息，不受预览分页限制。
6. 软件记住上次成功导出的格式，下次打开自动选择；取消保存或导出失败不更新。
7. 完成后可点击“打开导出文件”或“打开所在文件夹”。

日期筛选
开始日期默认 00:00:00，结束日期默认 23:59:59。日期和时分秒分别设置。点击时间右侧的时钟图标，可在与日期选择器相同风格的原生面板中选择时、分、秒，也可直接输入时间。手动修改时间后再次选择日期会保留时间。清空日期、“全部时间”或切换会话/账号后恢复默认时间。未选日期表示该侧不限。

导出内容
PDF：A4纵向分页，显示头像、聊天气泡、照片与表情，正文可搜索和复制。GIF固定显示首帧。语音、视频和文件保留消息记录，附件未嵌入；PDF不保留原始WXGF下载入口。
Markdown：默认单个.md文本文件，图片与表情用文字占位，适合检索、整理与AI分析。勾选“附带图片和表情”后，照片、自定义表情和微信内置表情一并导出。[笑脸]、[破涕为笑]等已知标签显示为22px行内小图，标签保留在图片替代文字和悬浮提示中。重复表情仅保存一份，同时生成同名_assets文件夹，图片使用相对路径引用，GIF保留动画；移动或分享时须同时携带文件夹。缺失资源在对应消息处标注。
HTML 内嵌头像、图片、表情包和内置表情；离线即可打开，无需附带图片文件夹。
照片来自本机缓存自动解密；JPEG、PNG、GIF 原字节保存，不再次压缩或裁剪。
微信 WXGF 使用本机 VoipEngine.dll 解码为显示用 JPEG，同时将解密后的原始 WXGF 数据嵌入 HTML，供另行下载留存。
已内置109种微信表情资源。已知表情标签显示为小图，标签文字仍保留在页面中用于搜索。
自定义表情支持微信 qq.com、qpic.cn 资源地址和群聊消息格式，保留GIF动画；下载后可从本地缓存离线导出。
找不到或无法唯一匹配的图片会明确标为缺失，导出完成状态会显示数量。
语音、视频和文件消息目前保留消息记录及原始消息内容，不嵌入这些附件文件。
“联网补全表情”只从消息携带的微信资源地址下载缺失表情，并核对MD5；关闭后只读取本地可用表情。聊天内容不会上传。

本地数据
默认位于 %LOCALAPPDATA%\WeChatLocalExporter，可在程序左下角“本地数据”打开。
目录中保存消息索引、解密副本、表情缓存和诊断日志。程序不修改、不删除微信源数据库或媒体。
数据库密钥仅在运行内存中使用，不保存明文密钥文件。
可使用“微信聊天导出器.exe --data 路径”指定单独的数据目录。

适用范围
当前在 Windows 10 64位、微信 4.1.15.13 上验证。数据库内存结构和图片派生方式可能随微信版本改变。
界面使用 Microsoft Edge WebView2 Runtime。本机已测试；换电脑运行时需要该运行时。
EXE 自带 Python 及所需库，不需要另装 Python。程序未做商业代码签名。
单文件 HTML 的图片采用内嵌编码；交给 AI 时适合解析正文后按需读图，直接把源码全部当提示词不一定节省输入开销。

源码与许可
本程序包含 wxlocal 项目的数据库及消息格式处理代码，按 AGPL-3.0 提供对应源码，详见附带源码包及 LICENSE。
构建：在源码目录使用 PowerShell 7 执行 pwsh -File build.ps1 -Python 你的Python路径。

1.0.1 修复
- 修复单文件 HTML 中头像数据存在但被默认样式覆盖的问题。
- 跳到最近会加载当前时间范围的末页，并定位到最后一条消息；媒体延迟加载时保持底部，用户主动向上浏览后停止跟随。

1.0.2 更新
- 目录选择改为 xwechat_files 根目录，自动枚举其直接子目录中的微信账号，忽略 all_users、WMPF 等公共目录。
- 账号下拉菜单只显示微信昵称和头像，不显示内部账号目录标识，并记住所选目录与账号。
- 未读取过且无本地资料的账号先显示“账号 1”“账号 2”等占位名；登录该账号并读取记录后自动补齐昵称与头像。
- 切换到尚未读取的账号会清空上一账号的会话预览，避免显示混淆。
